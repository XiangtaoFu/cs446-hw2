# Chat logs

Export every agent session into this folder and commit it (handout Section 6.4).

- In VS Code, run **Chat: Export Chat…** from the Command Palette. It saves the session as a JSON file.
- With another tool, export the complete transcript.
- Export a session before you delete it.
- Name each file by date and topic, for example `2026-11-12-round-robin.json`.

Never paste your course API key or GCP credentials into a chat. If one ends up in an exported file, replace only the key with `[REDACTED]` and contact the TA for a new key.
